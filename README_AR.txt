المحاسب الذكي — رسائل العملاء | الإصدار v0.5

- تعديل بيانات العملاء وحفظها محليًا.
- إعدادات اسم التطبيق والعملة وقناة الإرسال وقالب الرسالة.
- استيراد SQLite .db أو CSV مع استبدال القائمة القديمة بالكامل. إذا فشل الاستيراد تُمسح القائمة السابقة لمنع خلط البيانات.
- إرسال رسالة فردية من بطاقة العميل عبر SMS أو واتساب.
- إرسال الرسائل بالتتابع للعملاء المحددين، مع وضع {الاسم} و{الرصيد} في القالب.
- واتساب يفتح المحادثة والرسالة جاهزة، ويجب الضغط على إرسال داخل واتساب؛ لا يدعم الإرسال التلقائي الصامت.
- SMS يستخدم AndroidAPI.sendSMS إن وفره HTML to APK Builder، وإلا يفتح تطبيق الرسائل برسالة جاهزة. الإرسال الفعلي يعتمد على الجسر والصلاحيات.
- حفظ البيانات محليًا عبر LocalStorage؛ مسح بيانات التطبيق قد يحذفها.

طريقة الاستخدام: استورد ZIP داخل HTML to APK Builder، فعّل JavaScript، ثم ابنِ APK.
